# Qəhvə Satışlarının Təhlili | Power BI

Bu layihədə qəhvə sifarişləri, məhsullar və müştərilər haqqında məlumatlar əsasında interaktiv Power BI hesabatı hazırlanıb. Hesabat qəhvə növləri və ölkələr üzrə satışları müqayisə etməyə, satışların zaman ərzində dəyişməsini və müştərilərin loyallıq kartından istifadəsini araşdırmağa imkan verir.

## Layihənin Məqsədi

Qəhvə satışlarını müxtəlif istiqamətlər üzrə təhlil etmək, əsas göstəriciləri bir paneldə toplamaq və interaktiv qrafiklər vasitəsilə məlumatların müqayisəsini asanlaşdırmaq.

## Hesabatın Məzmunu

- Ümumi mənfəəti, sifariş sayını və bir sifariş üzrə mənfəəti göstərən kartlar.
- Qəhvə növləri üzrə ümumi miqdarı, mənfəəti və orta sifariş qiymətini müqayisə edən cədvəl.
- Satışların il və aylar üzrə dəyişməsini göstərən xətti qrafik.
- Qəhvə növləri və ölkələr üzrə satışları müqayisə edən sütun diaqramı.
- Müştərilərin loyallıq kartına sahib olub-olmamasına görə bölgüsünü göstərən dairəvi diaqram.
- İl və ay üzrə seçim etməyə imkan verən filtrlər.

## Məlumatların Strukturu

Hesabatda aşağıdakı cədvəllərdən istifadə olunub:

- **Sifarişlər** — sifariş tarixləri və satış məlumatları.
- **Məhsullar** — qəhvə növləri haqqında məlumatlar.
- **Müştərilər** — ölkə və loyallıq kartı məlumatları.

## İstifadə Olunan Alətlər və Bacarıqlar

- Microsoft Power BI Desktop
- DAX ölçüləri
- Məlumatların vizuallaşdırılması
- İnteraktiv filtrləmə
- Satış və müştəri məlumatlarının təhlili

## Layihə Faylları

- `coffee_report.pbix` — Power BI hesabatı və məlumat modeli.
- `coffeeOrdersData_task+.xlsx` — source data

## Hesabatı Necə Açmaq Olar?

1. Bu repozitoriyadan `coffee_report.pbix` faylını yükləyin.
2. Faylı Microsoft Power BI Desktop proqramında açın.
3. İl və ay filtrləri ilə istədiyiniz dövrü seçin.
4. Qrafiklərdəki elementlərə klikləyərək əlaqəli göstəriciləri araşdırın.

GitHub-da hesabatın ekran görüntüsünə baxmaq mümkündür. İnteraktiv imkanlardan istifadə etmək üçün `.pbix` faylını Power BI Desktop proqramında açın.
